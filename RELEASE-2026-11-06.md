## English — Changes

- Reorganized controls and marker search/scroll, custom shaded symbols and clearer water/terrain colors.
- Tilted terrain uses recorded heights and checked physical side bases; markers, radar and protection borders share the projection.
- Bounded background composition, prioritized received-chunk scanning and grouped server marker/protection synchronization.

Server: ZoneCore 2.1.2+ below 3. The client does not require Core. Clan, protection, region, arena and waystone integrations need their corresponding installed modules. Use the beta36 pair for all improvements.

Press M, drag to pan, scroll to zoom and use YO to recenter. Choose SUP/AUTO/Y layers, create a permitted marker and use SEGUIR for guidance. DISEÑO Y MINIMAPA controls icon, color, HUD size and style.

## Terrain and sharing / Terreno y datos compartidos

The client maps chunks Minecraft already received. The server sends rules, markers and protections; it does not render or stream prebuilt terrain. Chunk pregeneration does not remove the need to receive chunks. Connection speed, view distance, TPS and client performance still matter. / El cliente cartografía chunks recibidos; el servidor envía reglas y datos, no mapas prerenderizados. Pregenerar no evita recibir chunks y los tiempos dependen de red, distancia, TPS y cliente.

The tilted view represents cached heights and checked side bases, not a second full Minecraft camera. Unknown physical bases do not generate invented walls. Cave layers use the selected floor. Top-down remains available. / La vista inclinada representa alturas y bases comprobadas, no otra cámara completa. No inventa paredes para bases desconocidas; cuevas usa el suelo seleccionado y sigue disponible la vista cenital.

Personal markers are owner-only; clan markers follow current clan membership. The server groups pending updates and uses nearby protection queries without loading world chunks. Changed clan access is reflected on the next relevant synchronization. / Marcadores personales solo para dueño y clan según pertenencia actual. El servidor agrupa actualizaciones y consulta protecciones sin cargar chunks; accesos se reflejan en la próxima sincronización.

Client-only operation provides received-terrain mapping and local personal markers. Shared/global/clan features require the server module. Local markers are not automatically imported into server storage. / Sin módulo servidor hay mapa local y marcadores personales locales; funciones compartidas lo requieren. No se importan marcadores locales automáticamente.

## Installation / Instalación

Stop the affected instance, back up world/configuration, replace only the previous same-mod/same-side JAR and retain player data. Never install the dedicated and client JARs of one mod together. / Detén la instancia correspondiente, respalda mundo/configuración y sustituye solo el JAR del mismo mod y lado conservando datos. Nunca instales juntos los JAR dedicado y cliente del mismo mod.

## Validation scope / Alcance de verificación

Delivery checks cover marker audiences/quotas/persistence and tilted projection/physical faces. Cache previews are not screenshots of the final game geometry. Full multiplayer modpack and FPS/MSPT measurements are not established by these checks.

Las comprobaciones cubren audiencia/cuotas/persistencia de marcadores y proyección/caras físicas. Previews de caché no son capturas de geometría final del juego. No certifican modpack multijugador ni mediciones FPS/MSPT.
