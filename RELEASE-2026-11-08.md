## English — Requirements and changes

Minecraft 1.20.1, Forge 47.4.x, Java 17. ZoneCore 2.1.2–2.x is required only for ZoneMap Server. Install one side JAR per instance; beta38 keeps protocol zonemap-3.

Beta38 includes textured side faces and verified lower exterior surfaces beneath floating objects. It repairs missing walls beneath partial roofs such as slabs/stairs, preserves real transparency, excludes invisible terrain blocks and keeps visible facades behind nearby floating roofs. Style changes refresh received tiles; ZMT25 migrates readable older cache data without deleting markers. Surface-under-roof reconstruction is limited to SUP, received chunks, skylight and bounded scans; it is not a complete second Minecraft camera. Use beta38 clients and server with zonemap-3; server beta37 remains protocol-compatible. Core 2.1.2–2.x is server-only. Final corrected in-game tower rendering and full-modpack FPS/MSPT remain unverified.

Press M, pan/zoom and use YO to recenter. SUP supports the lower exterior surface; AUTO/Y CUEVA select cave layers. Keep your cache and let received areas refresh normally.

## Improvements since beta36 / Mejoras desde beta36

Beta37 added recorded side texture profiles and an exterior lower surface beneath floating objects, removing roof-height projected shadows. Beta38 repairs missing full side profiles when the top block is partial, continues through lower materials, skips invisible blocks and preserves a facade still visible beneath a neighboring floating roof. / Beta37 añadió perfiles laterales y suelo exterior inferior, retirando sombras proyectadas del techo. Beta38 corrige perfiles perdidos bajo bloques parciales, continúa por materiales inferiores, excluye invisibles y conserva fachadas visibles.

The roof still occludes what it covers from the camera; lower ground is not drawn through it. Cave layers and Y SUP do not receive the extra surface. Unknown or too-deep geometry can still remain fogged. / El techo sigue ocultando lo cubierto; no se dibuja suelo a través. Cuevas/Y SUP no usan esa superficie. Lo desconocido o demasiado profundo puede seguir en niebla.

Mapping remains client-side over received chunks. ZoneMap Server shares rules, markers and protections, not rendered terrain. Client/server beta38 are paired for distribution; server/shared logic matches beta37 with a version change only. / El cliente cartografía chunks recibidos; servidor comparte reglas y datos, no terreno renderizado. La pareja beta38 mantiene lógica servidor/compartida de beta37.

## Installation / Instalación

Stop the affected instance, back up world/configuration and replace only the previous same-mod/same-side JAR. Keep one JAR per mod per instance and preserve player data. / Detén la instancia correspondiente, respalda mundo/configuración y sustituye solo el JAR del mismo mod y lado. Conserva un JAR por mod e instancia y los datos de jugador.
