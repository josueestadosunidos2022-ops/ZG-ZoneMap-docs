# ZoneMap — 2026-10-17

## English — SERVER ONLY

Beta11 improves automatic height-band loading, negative-height recognition and layer scan prioritization. Adds square/circular HUD minimap choices without a decorative border and clips overlays to the circular view. Updates band cache format to ZMT4 while retaining supported older surface/cave data. Both sides must use beta11 (zonemap-3 protocol). Only chunks received by the client can be displayed.

Minecraft 1.20.1 / Forge 47.x / Java 17. ZoneCore: required (server). Stop the server/client before replacing JARs, keep only one version per side, and back up the world/configuration.

 Public protected distribution; private sources, obfuscation mappings and production account/configuration files are not included. Java obfuscation is not an absolute anti-decompilation guarantee. Original release checks and isolated protected-server startup are documented separately; graphical client, real multiplayer and full-modpack behavior are not certified by this upload.
